# Work Package A21: Lifecycle Automation

This package uses MTM and booking lifecycle state to drive retention, reminder, and refit automation.

## Purpose

Improve retention and repeat conversion with timed and state-aware lifecycle actions.

## Scope

1. Fit freshness reminders and reactivation campaigns.
2. Stale-profile prompts.
3. Pre-event and post-booking reminders.
4. Event map and trigger plan for Klaviyo/PostHog.

## Deliverables

- Lifecycle event map
- Klaviyo/PostHog trigger plan
- Saved-fit reminder flows
- Refit reminder flows
- Event-date automation hooks

## Acceptance Criteria

- Reminders are tied to fit freshness and booking timeline.
- Lifecycle actions are driven by real MTM state.
- Repeat purchase and revisit paths measurably improve.

## Dependencies

- A17 saved-fit/refit policy
- A18 orchestration state
- A22 analytics instrumentation enhances measurement

## Status

Specified and ready for implementation.
